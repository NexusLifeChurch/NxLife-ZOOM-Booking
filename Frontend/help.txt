3. จองประจำ
==============================

เมนูนี้สำหรับ Admin เท่านั้น


ใช้สำหรับกิจกรรมที่ต้องใช้ห้อง ZOOM
เป็นประจำในวันและเวลาเดิม

ตัวอย่าง

ประชุมทีม
ทุกวันจันทร์
เวลา 19:00 - 20:00


ในหน้านี้สามารถ

- เพิ่มกิจกรรมประจำ
- แก้ไขกิจกรรมประจำ
- พักการใช้งาน
- เปิดใช้งานอีกครั้ง
- ลบกิจกรรมประจำ


เพิ่มกิจกรรมประจำ

1. กด "+ เพิ่ม"
2. กรอกชื่อกิจกรรม
3. เลือกห้อง
4. เลือกวันในสัปดาห์
5. เลือกเวลาเริ่ม
6. เลือกเวลาสิ้นสุด
7. กำหนดวันที่เริ่ม
8. กำหนดวันที่สิ้นสุด ถ้ามี
9. กดบันทึก


พักกิจกรรม

ใช้เมื่อยังไม่ต้องการให้กิจกรรมนั้น
แสดงในตารางชั่วคราว

ข้อมูลจะยังอยู่
แต่จะไม่แสดงบน Home


เปิดใช้งาน

ใช้เปิดกิจกรรมที่เคยพักไว้
ให้กลับมาแสดงในตารางอีกครั้ง


ลบ

ใช้เมื่อต้องการลบกิจกรรมประจำนั้นออกจากระบบ

4. ผู้ใช้งาน
==============================

เมนูนี้สำหรับ Admin เท่านั้น


ใช้สำหรับจัดการผู้ที่สามารถเข้าใช้งานระบบ


ในหน้านี้สามารถ

- เพิ่มผู้ใช้งาน
- แก้ไขข้อมูลผู้ใช้งาน
- กำหนด Role
- กำหนด OTP
- เปิดหรือปิดการใช้งาน
- ลบผู้ใช้งาน


เพิ่มผู้ใช้งาน

1. กด "+ เพิ่มผู้ใช้งาน"
2. กรอก UserID
3. กรอก UserName
4. กำหนด OTP
5. เลือก Role
6. กำหนด Active
7. กดบันทึก


Role

USER

ใช้ระบบจองห้องทั่วไป


ADMIN

ใช้ระบบจองห้อง
และสามารถจัดการ

- กิจกรรมประจำ
- ผู้ใช้งาน


Active

Active = เปิดใช้งาน

Inactive = ปิดการใช้งาน

ผู้ใช้ที่ถูกปิดการใช้งาน
จะไม่สามารถเข้าใช้งานระบบได้

==============================
รายละเอียดและเงื่อนไขสำคัญของระบบ
==============================
ระบบมีการจอง 2 ประเภท

1. การจองครั้งเดียว
   ใช้เมนู Home และ My Booking

2. กิจกรรมประจำ
   เช่น กิจกรรมที่ใช้ห้องเดิมทุกวันจันทร์
   จัดการโดย Admin


==============================
1. การเข้าสู่ระบบ
==============================

เข้าใช้งานครั้งแรก

1. กรอก UserID
2. กรอก OTP 4 หลักที่ได้รับจากผู้ดูแลระบบ
3. เมื่อยืนยันสำเร็จ ให้ตั้ง PIN 4 หลัก
4. ครั้งต่อไปบนอุปกรณ์และ Browser เดิม
   สามารถใช้ PIN เข้าได้ทันที


สำคัญ

PIN เป็นรหัสสำหรับ Browser / อุปกรณ์นี้

หากเปลี่ยนเครื่อง
เปลี่ยน Browser
ล้างข้อมูลเว็บไซต์
หรือลบ Local Storage

อาจต้องยืนยันตัวตนและตั้ง PIN ใหม่


การกด Lock

Lock หมายถึงล็อกหน้าจอชั่วคราว

ระบบยังจำ UserID และ PIN ของเครื่องนี้ไว้
ไม่ได้เป็นการลบข้อมูลเข้าสู่ระบบ


ลืม PIN

1. เลือก "ลืม PIN"
2. ระบบจะสร้าง OTP ใหม่
3. ติดต่อผู้ดูแลระบบเพื่อขอ OTP
4. ใช้ OTP ยืนยันตัวตน
5. ตั้ง PIN ใหม่

เมื่อระบบสร้าง OTP ใหม่สำเร็จ
PIN เดิมใน Browser นี้จะถูกลบ

3. การ Refresh ข้อมูล
==============================

ข้อมูลหน้า Home ถูกโหลดมาเก็บไว้ใน Browser

การกดวันก่อนหน้า / วันถัดไป
ไม่ได้โหลดข้อมูลจาก Server ใหม่ทุกครั้ง

ข้อดีคือใช้งานได้เร็ว


หากมีคนอื่นเพิ่งจองห้อง
หรือ Admin เพิ่งแก้กิจกรรมประจำ
แล้วข้อมูลบนหน้าจอยังไม่เปลี่ยน

ให้กดปุ่ม Refresh บนหน้า Home


ปุ่ม Refresh จะโหลดข้อมูลล่าสุดจากระบบอีกครั้ง

5. กติกาเรื่องเวลา
==============================

เวลาที่สามารถเลือกได้มาจาก SlotTime ของระบบ

อย่าคิดว่าระบบกำหนดช่วงเวลาไว้ตายตัว
เช่น ทุก 15 นาที

หาก SlotTime เปลี่ยน
ตัวเลือกเวลาในระบบจะเปลี่ยนตาม


เวลาเริ่มต้องน้อยกว่าเวลาสิ้นสุด

ตัวอย่าง

10:00 - 11:00   ถูกต้อง

11:00 - 10:00   ไม่ถูกต้อง

==============================
9. หมายเหตุเรื่องเจ้าของ Booking
==============================

Booking ใหม่เก็บ CreatedBy เป็น UserName


แต่ระบบมีข้อมูลเก่าบางรายการ
ที่อาจเก็บเจ้าของเป็น UserLogin / UserID

ดังนั้น My Booking ถูกออกแบบให้รองรับข้อมูลทั้งเก่าและใหม่


สำคัญสำหรับการพัฒนาระบบในอนาคต

อย่าเปลี่ยนเงื่อนไข Owner
โดยดูเฉพาะ CreatedBy = UserName อย่างเดียว

ไม่เช่นนั้น Booking เก่า
อาจหายจากหน้า My Booking

==============================
11. กติกาของกิจกรรมประจำ
==============================

กิจกรรมประจำจะแสดงบน Home เมื่อ

1. Active = true
2. วันในสัปดาห์ตรงกัน
3. วันที่อยู่ตั้งแต่ StartDate เป็นต้นไป
4. ถ้ามี EndDate วันที่ต้องไม่เกิน EndDate


ตัวอย่าง

ทุกวันจันทร์
StartDate = 1 กันยายน
EndDate = 30 พฤศจิกายน

กิจกรรมจะแสดงเฉพาะวันจันทร์
ระหว่างวันที่ดังกล่าว


ถ้ากด "พัก"

Active จะเป็น false

รายการยังไม่ถูกลบ
แต่จะไม่แสดงเป็นกิจกรรมประจำบน Home

==============================
20. ถ้ามีปัญหา ให้ตรวจตามลำดับนี้
==============================

ข้อมูล Home ไม่ล่าสุด

→ กด Refresh


จองเวลาไม่ได้

→ ตรวจ Booking ห้องนั้น
→ ตรวจกิจกรรมประจำ
→ ตรวจ SlotTime


Booking หายจาก My Booking

→ ตรวจ CreatedBy
→ ตรวจ UserName
→ ตรวจ UserLogin / UserID เดิม


PIN ใช้ไม่ได้

→ ตรวจว่าใช้ Browser / เครื่องเดิมหรือไม่
→ ตรวจ Active ของ User
→ ถ้าจำไม่ได้ ใช้ลืม PIN และ OTP ใหม่


กิจกรรมประจำไม่ขึ้น Home

→ ตรวจ Active
→ ตรวจ DayOfWeek
→ ตรวจ StartDate
→ ตรวจ EndDate
→ ตรวจ Room
→ กด Refresh


ผู้ใช้เข้าไม่ได้ทั้งที่ PIN ถูก

→ ตรวจ Active
→ ตรวจ UserID
→ ตรวจ Backend / API
